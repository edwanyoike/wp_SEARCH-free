# Turbo Search for WooCommerce — 1.0

Initial WordPress.org release of the free core edition of Turbo Search for WooCommerce, plus a run of early refinements.

### New
- Live product search powered by fast native database search, so results feel instant.
- Background indexing that keeps your site running smoothly while search stays up to date.
- The index updates automatically whenever a product is saved, deleted, or its stock changes.
- Search covers product titles, SKUs, content, and categories.
- Full support for WooCommerce Multisite.
- The Settings tab shows what upgrading to Turbo Search Pro adds, with a preview of Pro-only features.
- The Settings page can occasionally show a dismissible announcement banner with news or offers.
- Turbo Search now has its own menu item in the sidebar instead of living under Settings.
- Plugin data management ("Delete Data on Uninstall" and the danger-zone data reset) now lives in its own "App Data" tab.

### Fixed
- Running the Free and Pro editions together on the same site is now blocked with a clear "Plugin Conflict" message, instead of silently causing issues.
- Removed an unnecessary internal file reference that could confuse WordPress during installation.
